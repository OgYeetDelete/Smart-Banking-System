NOTE: Protected endpoints require the header:
  Authorization: Bearer <your_jwt_token_here>

--- 1. CUSTOMER & AUTHENTICATION (with RBAC & TTL Security Logs) ---
Register Customer:
  POST http://localhost:5000/api/customers/register
  Body (JSON):
  {
      "name": "Rahul Sharma",
      "email": "rahul@gmail.com",
      "password": "password123",
      "phone": "9876543210",
      "role": "customer" // "customer" or "admin"
  }

Login Customer:
  POST http://localhost:5000/api/customers/login
  Body (JSON):
  {
      "email": "rahul@gmail.com",
      "password": "password123"
  }
  Returns JWT carrying customer id, email, and role.
  * Also logs login attempt (success/failure) into SecurityLog collection with 5-minute TTL!

Get All Customers (Admin Only):
  GET http://localhost:5000/api/customers/all
  Header: Authorization: Bearer <admin_token>

Get Real-Time Security & Login Attempt Logs (Admin Only, TTL Backed):
  GET http://localhost:5000/api/customers/security-logs
  Header: Authorization: Bearer <admin_token>


--- 2. BANK ACCOUNT MANAGEMENT ---
Create Bank Account:
  POST http://localhost:5000/api/accounts/create
  Header: Authorization: Bearer <token>
  Body (JSON):
  {
      "customerId": "6ab603a1dd6f2504c9908bcf",
      "accountType": "Savings" // "Savings", "Current", or "Salary"
  }

Get Accounts of Customer:
  GET http://localhost:5000/api/accounts/customer/:customerId
  Header: Authorization: Bearer <token>

Account Details by Account Number:
  GET http://localhost:5000/api/accounts/details/:accountNumber
  Header: Authorization: Bearer <token>

Account Summary Report (Aggregation Pipeline):
  GET http://localhost:5000/api/accounts/report
  Header: Authorization: Bearer <token>


--- 3. FUND TRANSFERS & LEDGER (MongoDB Transactions) ---
Transfer Funds (Atomic Transaction + Change Stream Trigger):
  POST http://localhost:5000/api/transfers/transfer
  Header: Authorization: Bearer <token>
  Body (JSON):
  {
      "fromAccount": "1790288503708",
      "toAccount": "1790313516202",
      "amount": 1000
  }
  * Validations: sender != receiver, balance >= amount, amount > 0.
  * Triggers real-time Change Stream fraud heuristics instantly upon commit.

Transaction History (Uses Compound Index { fromAccount: 1, transferredAt: -1 }):
  GET http://localhost:5000/api/transfers/history/:accountNumber
  Header: Authorization: Bearer <token>

Spending Analytics (Aggregation Pipeline):
  GET http://localhost:5000/api/transfers/analytics/spending
  Header: Authorization: Bearer <token>
